# Foundations

The ideas behind Instantiatio and iEWR are available here for deeper reading. You can go directly to [Try iEWR](/ewr/eng/try/) and return to these materials as questions arise.

- [Instantiatio](/ewr/eng/foundations/instantiatio/) — how intent becomes a working result through models, activity, and checking.
- [Nine AI-native-first principles](/ewr/eng/foundations/ai-native-first/) — goals, value, human agency, independent execution, and feedback.
- [System Formation](/ewr/eng/foundations/system-formation/) — how the system's purpose and state determine the necessary work.
- [Engineering Work Runtime](/ewr/eng/foundations/ewr/) — the environment supporting organization, execution, checking, and continuation.
- [FPF, Dynamic Method Generation, and MethodPack](/ewr/eng/foundations/methods/) — obtaining methods and preserving useful experience.
- [Why Codex needs EWR](/ewr/eng/foundations/why-codex-needs-iewr/) — how EWR organizes the agent’s work using methods and project context.

For the concrete 7.0.6 configuration, see [How iEWR works](/ewr/eng/how-iewr-works/).
