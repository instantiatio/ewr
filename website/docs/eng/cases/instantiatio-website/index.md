# Building and launching the Instantiatio website

The goal was to build a bilingual [Instantiatio](/ewr/eng/) website where visitors could quickly understand what iEWR is and try it for themselves. The source material included posts from a lab’s Telegram channel.

**The project owner set the task and chose the visual style.**

**The agent working in iEWR handled the entire build and release.** It planned the site structure and navigation, prepared the English and Russian content, implemented the design, automated publishing to GitHub Pages, and checked the live site. When the decision was made to separate the website from the application, the agent moved it to its own repository and verified it at the new address.

An independent agent reviewed the completed website after it went live. The review identified two issues in the case study materials. The archive for the quotation expiry tool lacked the original assignment needed to repeat the experiment. The GEO CRM case did not make clear what readers needed to run the commands in the report. The agent added the original assignment and its translation to the archive, explained next to the report that the commands require the full project package, and published the update. A follow-up review confirmed both fixes in English and Russian.
