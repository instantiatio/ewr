# Cases & Experiments

The task, the work performed, the result, and its checks make an experiment useful to others. The materials below connect assignments to results, checks, and conditions.

## Recursive System Formation — how iEWR developed itself

In a project that began with iEWR 6.0.8, the agent organized a transition to a new architecture. A separate instance set up from the published 7.0.6 release then continued development through 7.0.8. The case traces the handoff and the decisions the human retained.

[Read the iEWR self-development case](/ewr/eng/cases/recursive-system-formation/).

## GEO CRM: one project across agent environments

From a local CRM assignment to sales, stock, expense requests, and liquidity modelling in one application. Development continued through **Codex → DeepSeek Harness → Codex**; the saved context also supported two finance guides. The current 1.4.0-demo report records 36 tests, a connected business scenario, and an independent cash-flow calculation.

[Read the GEO CRM case and view the screenshots](/ewr/eng/cases/geo-crm/).

## Building and launching the Instantiatio website

The project owner set the task and chose the visual style. The agent in iEWR built the bilingual website, automated publishing, and released fixes after an independent review.
